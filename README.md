This repository contains a machine learning project that classifies emails as spam or not spam (ham) using Python’s scikit-learn library. The project utilizes the SMS Spam Collection Dataset from the UCI Machine Learning Repository, which contains labeled messages for training and testing.

The workflow includes data preprocessing, text vectorization using CountVectorizer, and model training with the Multinomial Naive Bayes algorithm, which is well-suited for text classification tasks. The trained model is then evaluated using accuracy, precision, recall, and F1-score, ensuring reliable predictions. Users can also test the model by inputting custom email messages to classify them as spam or not spam.

This project demonstrates the practical application of supervised machine learning in NLP, highlights feature extraction techniques, and provides a foundation for real-world spam detection systems.
